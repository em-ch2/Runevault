# Dependency scans

CI runs `npm audit --audit-level=high` for the frontend. For the backend it generates a CycloneDX inventory of resolved Maven dependencies and scans that inventory with OSV Scanner. No private API key or repository secret is required. The backend job requires a valid scan report and uploads it as a build artifact. Known findings are printed in the check log and remain in the report; they currently do not fail the pull request because the supported Spring 6.2 line has two unresolved findings. This is a reporting check, not a vulnerability-free release gate. Review the report before deployment.

Local review on 2026-10-17: `npm audit` reported zero vulnerabilities. The resolved Maven dependency graph was also scanned with OSV Scanner. Updating the Spring Boot 3.5 patch release and selected Jackson, Tomcat, PostgreSQL JDBC, and Log4j patch versions removed the other reported findings. Two Spring MVC 6.2.19 advisories remain: `GHSA-j9f9-w8pj-32f8` and `GHSA-pc63-qcmh-9cmg`. The affected view features are not used by Runevault, but the dependency scanner still flags the library. Do not suppress these results or force a major Spring upgrade without compatibility testing. Recheck for a supported Spring 6.2 patch before deployment.

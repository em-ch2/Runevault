# Dependency scans

CI runs `npm audit --audit-level=high` for the frontend and OWASP Dependency-Check for the resolved Maven backend dependencies. Configure the repository secret `NVD_API_KEY` before expecting the Maven scan job to pass; the key must not be added to Git or application environment files. The scan fails for CVSS 7 or higher and has no vulnerability suppressions.

Local review on 2026-10-17: `npm audit` reported zero vulnerabilities. The resolved Maven dependency graph was also scanned with OSV Scanner. Updating the Spring Boot 3.5 patch release and selected Jackson, Tomcat, PostgreSQL JDBC, and Log4j patch versions removed the other reported findings. Two Spring MVC 6.2.19 advisories remain: `GHSA-j9f9-w8pj-32f8` and `GHSA-pc63-qcmh-9cmg`. The affected view features are not used by Runevault, but the dependency scanner still flags the library. Do not suppress these results or force a major Spring upgrade without compatibility testing. Recheck for a supported Spring 6.2 patch before deployment and review the actual CI Dependency-Check report once `NVD_API_KEY` is configured.
